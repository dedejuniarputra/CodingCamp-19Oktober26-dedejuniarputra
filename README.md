# 📋 Life Dashboard

A simple to-do list dashboard to help you organize your day.

---

## Features

- 🕐 **Clock & Greeting** — shows current time, date, and greeting based on time of day
- ⏱️ **Focus Timer** — countdown timer with start, stop, and reset
- ✅ **To-Do List** — add, edit, complete, and delete tasks
- 🔗 **Quick Links** — save and open your favorite websites

## Bonus Features

- 🌙 Light / Dark mode
- 👤 Custom name in greeting
- 🚫 Prevent duplicate tasks

---

## How to Run

Just open `index.html` in your browser. No installation needed.

---

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- localStorage (for saving data)
